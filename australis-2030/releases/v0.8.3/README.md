# Australis v0.8.3 — stock-catalogue installer fix

This superseded download corrected the repeated stock catalogue divider error at line 624 of `sensors.ini`, which stopped earlier installers at 40% before replacing the old carrier. Authored mod INIs remained strictly validated, and missing real sensors or ammunition still stopped installation.

The model, speed settings and deck controller were carried forward from v0.8.2. The four separate ship definitions still produced extra dated class submenus.

The GitHub publication of the v0.8.3 installer was interrupted. Its correction is included in **[v0.8.4](../v0.8.4/README.md)**, along with the consolidated class list and flight-deck fixes. Use the [current network installer](../../../builds/install-ran-australis-v0.8.4-class-list-fix.sh).
